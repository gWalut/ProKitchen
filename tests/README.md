# Размещение тестов

Автотесты сервера находятся в Back/tests, клиента — в Front/src/tests, браузерные сценарии — в Front/tests/e2e. Команда npm test из корня запускает тесты сервера. Команда npm run check выполняет проверку API на отдельной новой временной базе. Проверка фронтенда npm --prefix Front test -- --runInBand пока имеет известные ошибки, описанные в docs/issues.
