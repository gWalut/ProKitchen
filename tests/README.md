# Размещение тестов

Сервер: `Back/tests`, команда `npm test` из корня (46 тестов). Клиент: `Front/src/tests`, команда `npm --prefix Front test -- --runInBand` (11 тестов).

`npm run check` проверяет API и PDF на отдельной временной базе. `npm run test:smoke` запускает три настоящих браузерных сценария на двух размерах экрана, каждый на отдельной временной базе. Подготовка Chromium и ограничения описаны в [актуальном протоколе](../docs/functional-audit.md).

Старые браузерные тесты в `Front/tests/e2e` не являются новым сквозным прогоном; новый набор находится в `Front/tests/smoke`.
