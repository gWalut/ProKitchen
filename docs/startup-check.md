# Протокол чистого запуска ProKitchen

Дата: 25 октября 2026 года. Проверка настроена Codex по поручению Саламатина Сергея.

Среда: стандартная новая VM GitHub Actions, ubuntu-latest, фактический образ Ubuntu 24.04; Node.js 22.20.0 и npm 10.9.3. Исходные node_modules, Back/.env и SQLite-база в репозитории отсутствуют; установка создаёт их заново. Кэш npm содержит пакеты для установки, а не готовую рабочую БД или node_modules.

Протокол: https://github.com/gWalut/ProKitchen/actions/runs/40227799078. Проверенная версия кода: 3fd3a9412ef093cfcbb93e27021f4159e3af2c1d.

| Шаг | Результат |
| --- | --- |
| npm run setup | Установлены зависимости по lock-файлам, созданы локальные настройки и новая схема SQLite |
| npm test | Все 32 теста из 6 наборов прошли |
| npm run check | Проверены повторная миграция, health, регистрация, вход, права, сохранённое блюдо и PDF |
| npm run build | Клиент собран |
| npm run dev | Запущены клиент и сервер; главная страница доступна, /api/v1/health через порт 5173 вернул HTTP 200 |

Для одинакового обращения к API на Windows и Linux прокси Vite направлен явно на 127.0.0.1:3000. Фоновые процессы CI останавливаются после проверки.

Визуальная проверка калькулятора ранее выполнена на Windows: 200 г картофеля по 0,05 рубля, 2 порции, результат 10 рублей всего и 5 рублей на порцию. В CI проверены тип и сигнатура PDF; визуальное качество PDF отдельно не оценивалось.

Описание изоляции GitHub-hosted runner: https://docs.github.com/en/actions/concepts/runners/github-hosted-runners.

Этот протокол подтверждает локальный сценарий SQLite. Он не подтверждает Docker/PostgreSQL и не заменяет согласование проекта и плана с преподавателем в issue product.
