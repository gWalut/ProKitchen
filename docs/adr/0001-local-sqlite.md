# Локальный запуск через SQLite

Статус: принято для лабораторной работы 1. Дата: 25 октября 2026 года.

В проекте уже есть SQLite и PostgreSQL, но контейнерный сценарий неполон: часть SQL и миграций рассчитана на SQLite. Для воспроизводимого базового запуска используется SQLite без внешнего сервера БД. Общая команда setup устанавливает зависимости, создаёт локальные настройки с отдельными секретами и применяет все SQLite-миграции.

Миграции выполняются в одной транзакции, учитываются в schema_migrations и проверяются по контрольным суммам. Повторное применение не удаляет данные. Изменение ранее применённого файла считается ошибкой; последующие изменения схемы должны добавляться отдельной миграцией.

Существующие каталоги Front и Back сохраняются: они уже разделяют клиент и сервер. Корневые src и tests описывают это размещение и точки входа, а не дублируют код.

PostgreSQL и Docker остаются отдельным направлением работ. До отдельного испытания они не считаются подтверждённым способом запуска. После проверки чистой Windows-папки полный локальный сценарий дополнительно прошёл в чистой Ubuntu VM GitHub Actions. Протокол: https://github.com/gWalut/ProKitchen/actions/runs/40227799078, docs/startup-check.md.
