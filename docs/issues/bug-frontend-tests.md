# Старые тесты фронтенда не соответствуют текущему приложению

Предлагаемая метка: bug. Issue: https://github.com/gWalut/ProKitchen/issues/3. Статус: открыто.

Воспроизведение в обычной копии файлов: npm --prefix Front test -- --runInBand.

LoginForm.test.tsx импортирует отсутствующий компонент. Тест apiClient использует старый путь и API MSW rest, тогда как установлена MSW 2.12.0. Jest также не разбирает ESM-зависимость until-async в этой конфигурации. Из трёх наборов только тест Button прошёл исходную проверку.

На исходной Windows-папке часть файлов с ReparsePoint не попала в автоматическое обнаружение Jest; результат одного набора нельзя считать результатом всей тестовой базы. Проверять нужно на обычном чистом клоне, где обнаружены все три файла.

Критерий завершения: тесты проверяют реальные LoginPage и ApiClient, корректно работают с установленными зависимостями и все обнаруживаются и проходят на Windows и в CI. Не удалять полезные сценарии авторизации ради успешного запуска.
