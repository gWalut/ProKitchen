# Не проходит проверка типов и линтер фронтенда

Предлагаемая метка: bug. Статус: требуется создание issue в новом репозитории.

Воспроизведение: после npm run setup выполнить npm --prefix Front run type-check и npm --prefix Front run lint.

Исходная проверка обнаружила 56 диагностик TypeScript и 68 ошибок/8 предупреждений ESLint. Есть отсутствующие импорты, несогласованные типы, устаревшие Storybook-примеры, any и нарушения доступности интерфейса. Сборка Vite при этом проходит, поскольку не заменяет проверку типов.

Критерий завершения: обе команды завершаются кодом 0; реальные ошибки исправлены без отключения правил или исключения действующего кода только ради успешного результата.
