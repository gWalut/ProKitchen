# Определить объём поддержки PostgreSQL и Docker

Предлагаемая метка: question. Issue: https://github.com/gWalut/ProKitchen/issues/4. Статус: открыто.

Локальный подтверждённый сценарий лабораторной работы использует SQLite. В репозитории также есть Compose с PostgreSQL, но custom_dishes и shared_favorites имеют SQLite-миграции, а модель refresh-токенов использует datetime('now'). Скрипт migrate теперь явно отказывается применять SQLite-миграции к PostgreSQL.

Нужно решить, входит ли PostgreSQL в объём семестра. Если входит — подготовить соответствующие миграции, проверить SQL запросы, конфигурацию CORS для порта 80 и полностью испытать Compose на чистых томах. Зафиксировать результат и устранить расхождения инструкции.

Критерий завершения: принято и записано решение по поддерживаемой БД; для каждого заявленного способа запуска есть успешный воспроизводимый протокол. До этого Docker/PostgreSQL обозначаются как неподтверждённые.
