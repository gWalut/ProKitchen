# product — ProKitchen для лабораторных работ

Опубликовано: https://github.com/gWalut/ProKitchen/issues/1. Согласование преподавателя ещё не получено.

**Автор:** Саламатин Сергей (gWalut). Работа индивидуальная. Проект собственный.

ProKitchen помогает повару рассчитывать себестоимость, хранить состав блюд и формировать PDF-этикетки. Роли: пользователь и администратор. Основные сущности: пользователь, блюдо, ингредиент, аллерген. Стек: React, TypeScript, Vite, Node.js, Express, SQLite; поддержка PostgreSQL требует отдельной проверки. Лицензия авторского кода — ISC.

Паспорт: docs/00-project.md. Репозиторий: https://github.com/gWalut/ProKitchen. Публичный доступ к коду, issues и PR открыт.
