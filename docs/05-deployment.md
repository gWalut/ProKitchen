# Сборка и выпуск

Подтверждаемый базовый сценарий: Node.js 22.20.0, локальный SQLite, команды npm run setup и npm run dev. Сборка фронтенда: npm run build. Выпуск, версия, окружение развёртывания и окончательный протокол будут оформлены в лабораторной работе 6. Docker/PostgreSQL до отдельной проверки не являются подтверждённым сценарием.
