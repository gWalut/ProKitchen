# Шрифты для генерации PDF

Эта папка содержит шрифты DejaVu Sans, необходимые для корректного отображения русского текста в PDF-документах.

## Установка

Шрифты автоматически загружаются при выполнении:
```bash
npm install
```

Или вручную:
```bash
npm run setup-fonts
```

## Используемые шрифты

- **DejaVuSans.ttf** - обычный шрифт
- **DejaVuSans-Bold.ttf** - жирный шрифт

Оба шрифта поддерживают кириллицу и другие Unicode символы.
