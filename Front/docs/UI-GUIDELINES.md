# Рекомендации по разработке UI

## Доступность и UX

### Mobile-first подход
- Все компоненты оптимизированы для мобильных устройств
- Используется max-w-mobile (480px) для контейнеров
- Крупные интерактивные элементы (минимум 44px)
- Читаемые шрифты с правильным контрастом

### Доступность (a11y)
- Все интерактивные элементы имеют aria-labels
- Модальные окна используют focus-trap и закрываются по Esc
- Автодополнение реализовано с ролями listbox/option
- Темная тема следует системным настройкам

### Состояния загрузки
- Skeleton компоненты при загрузке списков
- Спиннеры на кнопках для async операций
- Toast уведомления для результатов действий

## Валидация

### Поля ввода
- Email: стандартный HTML5 pattern + regex
- Пароль: минимум 8 символов
- Даты: конвертация в ISO формат
- Количество: строго больше 0

## Структура проекта

### API слой (/src/api/*)
- client.ts - базовый класс для HTTP запросов
- endpoints.ts - типизированные endpoint'ы
- services.ts - бизнес-логика и трансформация данных

### Контексты (/src/contexts/*)
- ThemeContext - управление темной темой
- AuthContext - авторизация
- UIContext - глобальное состояние интерфейса

### Компоненты (/src/components/*)
- /ui/* - базовые компоненты
- Специфические компоненты на верхнем уровне
- Компоненты страниц в /pages/*

## Использование ThemeProvider

```tsx
// App.tsx
import { ThemeProvider } from '@/contexts/ThemeContext';

function App() {
  return (
    <ThemeProvider>
      <div className="dark:bg-dark-card">
        {/* content */}
      </div>
    </ThemeProvider>
  );
}

// Использование в компонентах
import { useTheme } from '@/contexts/ThemeContext';

function MyComponent() {
  const { theme, toggleTheme } = useTheme();
  return (
    <button onClick={toggleTheme}>
      {theme === 'dark' ? '🌞' : '🌙'}
    </button>
  );
}
```

## Стили

### Tailwind утилиты
- Используйте встроенные утилиты
- dark: префикс для темной темы
- focus-visible: для клавиатурной навигации
- touch-target-size для мобильных

### Цветовая схема
- brand-* - основные цвета бренда
- accent-* - акцентные цвета
- dark-* - цвета для темной темы
