# 🎨 Обновление дизайна CookAssistent

## Обзор изменений

Приложение получило полное обновление дизайна с современными компонентами, градиентами и анимациями.

## 🌟 Основные улучшения

### 1. **Цветовая схема и градиенты**
- Добавлены градиентные фоны для всех страниц
- Используются мягкие переходы от голубого через белый к фиолетовому
- Темная тема теперь с градиентами от серого через фиолетовый к синему

### 2. **Компоненты**

#### **Кнопки (Button)**
- Градиентные кнопки с эффектом hover
- Увеличенные отступы (48px высота)
- Тени и анимации масштабирования
- Улучшенный loading индикатор

#### **Поля ввода (Input)**
- Увеличенная высота и отступы
- Толстые бордеры (2px)
- Эффекты hover и focus
- Улучшенная типографика для labels

#### **Карточки плиток (LargeTileButton)**
- Градиентные фоны
- Эффекты hover с масштабированием
- Цветная полоска снизу при наведении
- Увеличенные иконки (5xl размер)

### 3. **Страницы**

#### **Главная страница (MainPage)**
- Градиентный фон
- Улучшенный заголовок с градиентным текстом
- Анимация появления карточек с задержкой
- Современная карточка предупреждения для гостей
- Адаптивная сетка (2 колонки на desktop, 1 на mobile)

#### **Страница входа (LoginPage)**
- Градиентный фон с декоративными элементами (blur bubbles)
- Полупрозрачная карточка с backdrop blur
- Иконка в цветном градиентном квадрате
- Улучшенная кнопка смены темы
- Разделитель между кнопками

#### **Страница регистрации (RegisterPage)**
- Аналогичный дизайн с зелено-синей цветовой схемой
- Плавные анимации для ошибок (shake)
- Современная типографика

### 4. **Новые компоненты**

#### **Card**
- Базовый компонент для карточек
- Варианты: обычный и градиентный
- Поддержка hover эффектов
- Части: CardHeader, CardContent, CardFooter

#### **Badge**
- Компонент для меток и тегов
- Варианты: default, primary, success, warning, error, info, outline
- Поддержка иконок
- Градиентные цвета

#### **LoadingSpinner**
- Двойной вращающийся спиннер
- Размеры: sm, md, lg
- Режим fullScreen
- Опциональный текст

#### **PageHeader**
- Унифицированный заголовок страниц
- Поддержка иконок
- Кнопка "Назад"
- Слот для actions

### 5. **Анимации**

Добавлены CSS анимации:
- `fade-in` - плавное появление
- `slide-up` - появление снизу вверх
- `scale-in` - масштабирование
- `shake` - тряска (для ошибок)

### 6. **Tailwind конфигурация**

Обновлены стили в `tailwind.css`:
- Базовый градиентный фон для body
- Улучшенные классы для кнопок и инпутов
- Готовые классы для карточек
- Классы для градиентного текста
- Кастомные анимации

## 🎯 Результат

- Современный и привлекательный дизайн
- Улучшенный UX с анимациями и hover эффектами
- Консистентность между компонентами
- Поддержка темной темы
- Адаптивность для мобильных устройств

## 📦 Использование новых компонентов

```tsx
import { Card, CardHeader, CardContent, CardFooter } from '@/shared/components';
import { Badge } from '@/shared/components';
import { LoadingSpinner } from '@/shared/components';
import { PageHeader } from '@/shared/components';

// Пример карточки
<Card hover gradient>
  <CardHeader>
    <h2>Заголовок</h2>
  </CardHeader>
  <CardContent>
    <p>Контент карточки</p>
  </CardContent>
  <CardFooter>
    <Button>Действие</Button>
  </CardFooter>
</Card>

// Пример badge
<Badge variant="success" icon="✓">Активно</Badge>

// Пример загрузки
<LoadingSpinner size="lg" text="Загрузка..." />

// Пример заголовка
<PageHeader 
  title="Настройки" 
  icon="⚙️"
  showBackButton 
/>
```

## 🚀 Следующие шаги

Рекомендуется обновить остальные страницы (CalcPage, AllergensPage, и т.д.), используя новые компоненты Card, Badge, PageHeader для единообразия дизайна по всему приложению.
